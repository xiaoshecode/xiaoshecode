准备环境使用入口目录结构检查结果

准备环境

  • Node.js 22.19+，npm 9.6.5+；最低 Node 版本与锁文件中的 undici 要求一致。
  • npm ci：安装 package-lock.json 锁定的依赖。

使用入口

  • npm run dev：本地开发。
  • npm run build：构建到 dist/。
  • npm run preview：预览构建产物。
  • 网站：https://xiaoshecode.github.io/

目录结构与职责

  • src/pages/index.astro：页面组合。
  • src/components/：布局和内容组件。
  • src/data/：双语文案、论文、动态和项目数据。
  • src/content.config.ts：内容字段校验。
  • src/scripts/main.ts：语言、主题和滚动交互。
  • src/styles/global.css：全站样式。
  • public/：静态资源；dist/：忽略的生成产物。
