rtmq

用 MkDocs 维护 RTMQ、Seq 和 Device 使用手册；实验控制软件本体不在本仓库。

本轮源码与 README ↗默认分支提交 ↗全部仓库
准备环境使用入口目录结构检查结果

准备环境

  • Python 3.10+；创建并激活虚拟环境。
  • python -m pip install -r requirements-docs.txt

使用入口

  • python -m mkdocs serve：本地预览。
  • python -m mkdocs build --strict：构建并检查文档。
  • 使用手册：https://xiaoshecode.github.io/rtmq/

目录结构与职责

  • docs/：Markdown 文档源文件；Seq* 与 Device* 按设备分别组织。
  • docs/figure/：插图。
  • mkdocs.yml：导航、主题、搜索与日期插件。
  • requirements-docs.txt：文档环境约束。
  • .github/workflows/ci.yml：部署到 gh-pages。
  • site/：生成产物，现已从源码索引移除并忽略。
