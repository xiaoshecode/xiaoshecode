cuquantum_benchmark_init

cuQuantum Benchmarks 的 QFT 递增与 Qiskit/Aer 随机电路运行脚本。

准备环境使用入口目录结构检查结果

准备环境

  • Python 3.10+；Bash；GPU 路径另需兼容 NVIDIA GPU/驱动/CUDA/后端。
  • 先按 NVIDIA cuQuantum Benchmarks 上游文档安装匹配版本。
  • bash benchmark_env_install.sh /path/to/cuQuantum/benchmarks

使用入口

  • python benchmark_test.py --start-qubits 1 --max-qubits 20 --timeout 300
  • NUM_QUBITS=12 BENCHMARK_NAME=random bash benchmarks.sh

目录结构与职责

  • benchmark_test.py：可导入、范围受限、带每次子进程超时的运行器与 CLI。
  • benchmarks.sh：Qiskit/Aer 随机电路调用示例。
  • benchmark_env_install.sh：从显式指定的上游目录安装。
  • cuquantum_env_install.sh：历史 CUDA-Q/Conda 配方，本轮未执行。
  • tests/test_benchmark.py：子进程边界回归。
  • pyproject.toml、.editorconfig、.gitignore：Ruff、编辑器与产物规范。

本次整理

  • 以 subprocess.run(timeout=...) 终止超时进程，monotonic 计时；限制最大量子比特范围。
  • 导入不执行基准；缺失命令返回127，超时返回124，后端错误保留退出码。
  • Shell 示例恢复 benchmark/nqubits 必需参数，使用严格错误处理与显式安装目录。
  • 新增 README、EditorConfig、Ruff 配置、忽略规则和回归测试。
