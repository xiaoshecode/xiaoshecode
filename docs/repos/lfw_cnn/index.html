lfw_cnn

准备环境使用入口目录结构检查结果

准备环境

  • python -m venv .venv
  • 激活环境后按 PyTorch 官方平台选择安装 torch/torchvision。
  • python -m pip install -r requirements.txt
  • 准备图片目录及其父目录的 male_names.txt / female_names.txt；每行是图片相对路径。

使用入口

  • from LFW_pytorch_loader import LFW; dataset = LFW('dataset/easy_trainingdata', data_count=500, seed=42)
  • 通过 torch.utils.data.DataLoader(dataset, batch_size=32) 使用；不同图片尺寸需先传入 Resize transform。
  • 旧接口：from lfw_loader import DataLoader; data = DataLoader('dataset/easy_trainingdata'); data.loadLFW_label(); data.loadLFW_facedata(); data.getTrainData()

目录结构与职责

  • lfw_data.py：全部标签路径校验、规范路径去重、跨类冲突检查及平衡采样。
  • lfw_loaders.py：PyTorch Dataset 和历史批量加载器的共享实现，避免兼容模块循环导入。
  • lfw_loader.py：原 DataLoader 入口，并保留维护草稿中的 LFW 导出。
  • LFW_pytorch_loader.py：原 LFW 入口，并保留维护草稿中的 DataLoader 导出。
  • tests/test_loaders.py：合成图片、旧导入 API、路径别名与采样前校验回归。
  • requirements.txt、pyproject.toml、.editorconfig：依赖下限和格式规范。

  • 测试环境 Windows/Python3.13.12、torch2.15.0+cpu、torchvision0.29.2+cpu、numpy2.5.4、Pillow13.0.0；未跑GPU训练或真实LFW数据。
