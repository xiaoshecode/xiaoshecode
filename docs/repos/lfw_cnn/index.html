lfw_cnn

准备环境使用入口目录结构检查结果

准备环境

  • python -m venv .venv
  • 激活环境后按 PyTorch 官方平台选择安装 torch/torchvision。
  • python -m pip install -r requirements.txt
  • 准备图片目录及其父目录的 male_names.txt / female_names.txt；每行是图片相对路径。

使用入口

  • from lfw_loader import LFW; dataset = LFW('dataset/easy_trainingdata', data_count=500, seed=42)
  • 通过 torch.utils.data.DataLoader(dataset, batch_size=32) 使用；不同图片尺寸需先传入 Resize transform。
  • 旧接口：from LFW_pytorch_loader import DataLoader; data = DataLoader('dataset/easy_trainingdata'); data.loadLFW_label(); data.loadLFW_facedata(); data.getTrainData()

目录结构与职责

  • lfw_data.py：标签读取、去重、平衡采样、路径与数量校验。
  • lfw_loader.py：惰性 PyTorch Dataset，__len__/__getitem__ 及自定义 transform。
  • LFW_pytorch_loader.py：保留历史方法名的批量加载和65/20/15划分。
  • tests/test_loaders.py：合成图片回归。
  • requirements.txt、pyproject.toml、.editorconfig：依赖下限和格式规范。

本次整理
