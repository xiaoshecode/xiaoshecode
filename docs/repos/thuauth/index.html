thuauth

Windows 清华校园网认证与保活客户端：Python asyncio/aiohttp，双栈状态、按需登录与可配置流量。

准备环境使用入口目录结构检查结果

准备环境

  • uv sync --locked --group dev
  • uv run thuauth --help
  • uv run thuauth config check -c config.example.json

使用入口

  • 用户在自己的交互终端执行 uv run thuauth init，凭据保存在本机。
  • uv run thuauth status --json
  • uv run thuauth keep
  • 真实校园网操作请先阅读 docs/campus-validation.md，本轮未执行。

目录结构与职责

  • src/thuauth/：CLI、配置、认证、HTTP、守护、流量、限速与日志。
  • src/thuauth/protocol/：纯协议编码与响应解析。
  • tests/：假服务器、协议向量、并发/取消/配额/ACL回归。
  • docs/：架构、运行契约、开发、校园网验收和本轮维护记录。
  • references/GoAuthing/：只读固定上游源码，保持原始来源许可。
  • pyproject.toml、uv.lock：包元数据和锁定依赖。
