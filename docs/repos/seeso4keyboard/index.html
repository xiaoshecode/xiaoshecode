准备环境使用入口目录结构检查结果

准备环境

  • Windows + C++11 + CMake 3.5+；自行提供 SeeSo SDK/授权及 OpenCV C++。
  • opencv/、seeso/ 各需 CMakeLists.txt 包装文件，导出同名 target 及 OPENCV_DLL/SEESO_DLL。
  • cmake -S . -B build/app
  • cmake --build build/app --config Release

使用入口

  • 在本机环境设置 SEESO_LICENSE_KEY 后启动 build/app/Release/seeso_windows.exe。
  • 摄像头索引 0；C 校准、Esc 退出。gaze.csv 每次启动重新写入；AVI/校准文件保存到工作目录。
  • cmake -S . -B build/support -DSEESO_SUPPORT_TESTS_ONLY=ON
  • cmake --build build/support --config Release
  • ctest --test-dir build/support -C Release --output-on-failure

目录结构与职责

  • main.cpp: 环境变量、初始化、校准与 GUI 循环
  • camera_thread.*: 摄像头线程和本地视频记录
  • tracker_manager.*: SeeSo 回调和校准状态
  • view.* / drawables.h: GUI 绘制
  • priority_mutex.* / simple_signal.h: 同步和事件
  • utils/CSVLogger.hpp: CSV 文件与转义
  • tests/support_test.cpp: 独立回归测试

本次整理

  • 源码密钥改从 SEESO_LICENSE_KEY 读取；未改写公开历史。
  • 修复 initialize 漏传校准数据；新增缺失 CSVLogger.hpp，补齐标准库头文件。
  • 非阻塞高优先级 try-lock 不注册等待者，避免计数泄漏及无人通知的低优先级等待死锁。
  • 校准完成重置进行中标记，允许再次校准；空数据不发送给 SDK。
  • VideoWriter 改为值对象，先 join 再 release，修复失败路径未初始化指针访问；默认用摄像头取代个人绝对视频路径，跳过空帧。
  • 增加 SDK-independent CMake 测试模式、README、.editorconfig、输出与本地 SDK 忽略规则。
