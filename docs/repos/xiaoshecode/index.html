准备环境使用入口目录结构检查结果

准备环境

  • Python 3.10+；只使用标准库，无额外依赖。

使用入口

  • python scripts/build_docs.py：生成所有项目页面。
  • python scripts/check_docs.py：检查记录完整性与站内链接。
  • python -m http.server 8000 --directory docs：预览。
  • GitHub Pages 当前从维护分支 codex/repository-maintenance-20261030 的 /docs 发布。

目录结构与职责

  • README.md：GitHub 个人资料与文档入口。
  • data/repositories/：逐仓库结构化记录。
  • scripts/build_docs.py：静态页面生成器。
  • scripts/check_docs.py：站内校验。
  • docs/assets/：样式和搜索脚本。
  • docs/repos/<name>/index.html：独立项目文档。
