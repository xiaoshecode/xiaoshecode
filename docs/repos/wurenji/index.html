准备环境使用入口目录结构检查结果

准备环境

  • Linux + ROS 1/catkin + C++14 + OpenCV；厂商 SDK 和 .so 必须匹配目标 CPU。
  • source /opt/ros/melodic/setup.bash
  • 将检出作为 catkin_ws/src，执行 catkin_make；包依赖需先满足，完整构建未验证。

使用入口

  • 离线独立 Python 3 环境：python -m pip install numpy opencv-python-headless
  • python -m unittest discover -s tests -v
  • 部署脚本顺序：startpsdk.sh、startroscore.sh、startuavservice.sh、startimage.sh、pass_ring.sh。运行前检查脚本机器路径；最后一步会真实起飞。

目录结构与职责

  • raspicam_node/: ttauav_node 消息/服务、通信与视觉
  • raspicam_node/src/cv/: 圆环图像算法
  • raspicam_node/src/test_scripts/pass_ring.py: 飞行状态机
  • image_pub/: 图像发布及厂商 RTSP 库
  • Decodertest/: 独立解码器示例
  • tests/: 不连接 ROS 的离线视觉测试
