准备环境使用入口目录结构检查结果

准备环境

  • pnpm install --frozen-lockfile
  • python scripts/build_data.py
  • pnpm dev

使用入口

  • 站点：https://xiaoshecode.github.io/paper4qi/
  • 本地：http://localhost:4321/paper4qi/
  • pnpm build
  • python scripts/validate_agent_data.py --site-dir dist

目录结构与职责

  • data_src/：版本控制的数据与策展输入。
  • scripts/：数据构建、验证、周更抓取、Sites辅助工具。
  • src/：Astro页面、组件、TypeScript浏览交互、内容、样式。
  • public/data/、dist/：忽略的构建产物。
  • sites/worker.mjs：静态资源及6个只读MCP工具。
  • docs/：来源、Agent访问、维护说明。
  • .github/workflows/：现有部署和周更流程，保持不变。
